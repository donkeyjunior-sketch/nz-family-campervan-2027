# NZ Family Campervan Trip 2027 — Travel Planner MVP

A responsive Chinese-language travel-planning website prototype for a family of four planning a New Zealand campervan trip in July 2027.

## Included in this MVP
- Travel dashboard for a family trip
- Draft day-by-day itinerary (clearly labeled as a sample, not a confirmed plan)
- Editable trip settings and budget entries in browser local storage
- Booking checklist
- Winter-driving reminders and links to official NZTA road conditions
- Responsive layout for desktop and mobile

## Run locally
This prototype is static and does not require a backend:
1. Unzip this project.
2. Open `index.html` in a modern browser.

For a production version with shared access and persistent data, the next phase should add FastAPI + PostgreSQL, authentication, itinerary CRUD APIs, booking records, budget categories, and database migrations.

## Important
The sample route is illustrative only. July is winter in New Zealand. Check official road and weather conditions before driving. Milford Road can have snow/ice and avalanche-related restrictions; consult official NZTA and Department of Conservation updates.
